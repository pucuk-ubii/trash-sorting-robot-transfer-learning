# Dataset reference

- Name: TrashNet
- Source repository: https://github.com/garythung/trashnet
- Common classes: cardboard, glass, metal, paper, plastic, trash.
- Dataset is not redistributed in this project. Download from the source repository and review its license/terms before reuse.
- Recommended reporting: document the dataset version, number of images per class, split strategy, validation metrics, and examples of errors.
